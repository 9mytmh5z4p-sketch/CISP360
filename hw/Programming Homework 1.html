Homework Assignment 1:
Personalized C++ Calculator Program

Assignment Overview

For Homework Assignment 1, you will create a complete C++ program based on a creative theme of your choice. Your program should ask the user for several pieces of information, perform calculations, and display the results in a clear, formatted way.

Everyone must meet the same technical requirements, but your theme, variable names, greeting, input prompts, calculations, and output wording should be personalized. This helps you practice the required C++ concepts while making your program distinct from your classmates’ work.

Your program must compile, run, and produce logically correct output.

Academic Integrity and AI Use

You may use AI tools to help explain concepts, review error messages, or understand lecture material. You may not use AI to write your program code for you.

Your submitted work should reflect your own thinking, theme, structure, variable names, calculations, and output design. Personalized programs help reduce plagiarism similarity scores. The target plagiarism score is under 50%.

Theme Selection Guidance

Choose a theme that gives you natural reasons to ask for input, calculate values, and display results.

Good themes usually have a clear scenario, several numeric inputs, calculations that make sense, personalized wording, and output that would be useful to someone.

Strong theme examples:

  • Space Mission Calculator: fuel estimates, travel time, supply needs
  • Recipe Nutrition Tracker: servings, ingredient amounts, calories per serving
  • Road Trip Planner: miles, gas cost, fuel efficiency, total trip estimate
  • Fantasy Character Stats: health, attack power, inventory weight, score rating
  • Home Energy Calculator: daily usage, cost per kilowatt-hour, monthly estimate
  • Event Budget Planner: guests, food cost, venue cost, total cost per person

Avoid themes that are too simple. A program that only asks for two numbers and adds them is not enough for this assignment.

Program Structure Guidelines

Organize your program in a clear order:

  1. Source file header
  2. Include directives
  3. using namespace std;
  4. int main()
  5. Program Greeting
  6. Variable declarations and constants
  7. User input section
  8. Calculation section
  9. Formatted output section
  10. return 0;
  11. IPO Model block comment
  12. Execution Trace Model block comment

Use comments to label major sections, but do not comment every single line. Comments should help the reader understand the purpose of each section.

Common Mistakes to Avoid

  • Forgetting the source file header
  • Writing a generic greeting instead of a personalized Program Greeting
  • Submitting a file that does not compile
  • Using integer division when a decimal answer is needed
  • Forgetting fixed and setprecision for decimal output
  • Using unclear variable names like a, b, x, or num
  • Choosing a theme but using prompts and output that do not match it
  • Putting the IPO Model or Execution Trace outside block comments
  • Uploading the .cpp file instead of the required .txt file
  • Letting AI write the code instead of writing it yourself

Tips for Success

Start with your theme first. Decide what your program is supposed to help someone calculate, then choose inputs and calculations that fit that scenario.

Build your program in small steps. First make the greeting work. Then add variables. Then add input. Then add one calculation at a time. Compile and run often.

Use realistic test values. If your result seems impossible for your theme, check your data types, arithmetic, and division carefully.

Make your program look like your work. Personalized names, prompts, labels, and theme details will make your submission stronger and more original.
